Проекты DMDP

Сайты и Android-приложения: тренажёры для школьников, полезные инструменты и игры.

Обучение

  • Учим стихи

    uchim-stihi.ru

    Помогает детям 3–12 лет выучить стихотворение к празднику: по шагам и в игровой форме.

  • StudyFlow

    dz-tracker.ru

    Канбан-доска домашних заданий для школьников 10–17 лет и их родителей.

  • 2+3

    Математика, 2 класс

    math-training.dmdp.ru

    Тренажёры по учебнику Моро: состав числа, переход через десяток, задачи и геометрия.

  • Ab

    Английский, 2 класс

    english-training.dmdp.ru

    Тренажёры к учебнику «Английский в фокусе»: алфавит, слова, фразы и чтение.

  • Аа

    Русский язык, 2 класс

    russkij-yazyk.dmdp.ru

    Словарные слова по учебнику Канакиной — упражнения прямо в браузере, без регистрации.

Инструменты

  • Money Envelope

    money-envelope.dmdp.ru

    Конверт для денежного подарка с вашей фотографией и поздравлением: PDF для печати на A4.

  • Gift Planner

    gift-planner.dmdp.ru

    Кому что подарить к празднику, сколько потратить и что осталось купить. Данные хранятся в браузере.

  • MD

    Excel2Markdown

    excel2markdown.dmdp.ru

    Превращает таблицы Excel в Markdown или JSON — все листы сразу, результат одним архивом.

  • Тишина

    Приложение для Android в RuStore

    Измеритель уровня шума: без рекламы и трекеров, работает без интернета.

Игры и хобби

  • ✂

    Конструктор поделок

    craft-picker.dmdp.ru

    Отметьте материалы, которые есть дома, — сервис подберёт поделки по возрасту ребёнка.

  • Снежинки

    snowflakes.dmdp.ru

    Вырезайте бумажные снежинки на экране: надрежьте сложенный лист и разверните узор. Работает без интернета.

  • NetWalk

    netwalk-game.dmdp.ru

    Головоломка: поворачивайте кабели, чтобы подключить все компьютеры к серверу.

    Версия для Android в RuStore

  • Sudoku Craft

    Приложение для Android в RuStore

    Судоку с вариантными режимами и подсказками, которые учат решать. Работает без интернета.
